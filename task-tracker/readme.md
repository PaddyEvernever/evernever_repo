Task tracker project

Main idea:
The utility helps to build a daily / weekly / monthly schedule

Requirements:

1. User has to have an ability to add the task
2. User has to have an ability to update the task
3. User has to have an ability to delete the task
4. User has to have an ability to mark the task as completed
5. User has to have an ability to rollback the task completion
6. User has to have an ability to add a deadline
